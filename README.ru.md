# dsh-plugins

Дерево пакетов фермы агентов на машине sadik: плагины для платформы агентов DeepSeek Harness (DSH), семейство памяти
`dsh-pamyat` и служебные программы машины, на которой живут агенты. Всё здесь написано и работает в бою; комментарии в коде
называют ловушки, из-за которых строка появилась.

Наружу дерево пока не публикуется (решение владельца): пакеты ставятся с этой машины — npm-пакеты из локальной полки
тарболов по lock-файлу `/opt/agent-plugins`, служебные — копированием файлов по записи реестра машины
(`/etc/agent-registry/plugins.yaml`, поле `derevo.files`). Как ставить и проверять каждый пакет — в его README.

## Что здесь: 40 пакетов, пять групп

- **А — Семейство памяти `dsh-pamyat`** (12)
- **Б — Плагины агента: подписка, инструменты, каналы связи** (7)
- **В — Сторожа и приборы машины** (6)
- **Г — Свои службы — не плагины агента** (2)
- **Д — Служебные программы машины sadik — только исходники** (13)

Группа А — раздел «Семейство памяти»; группы Б–Д — подразделы раздела «Плагины и программы».

`dsh-subscription-gateway`, `dsh-tool-bridge` и `dsh-schedule-guard` — одна история, и каждый полезен сам по себе: агент на подписке
(`dsh-subscription-gateway`), инструменты платформы для модели на таком маршруте (`dsh-tool-bridge`) и потолок самопобудки, если
агенту дали будить себя самому (`dsh-schedule-guard`). Заметки об устройстве всех трёх — в [`docs/DESIGN.md`](docs/DESIGN.md).

## Проверка

У каждого пакета есть стенды. Стенд, которому нечего проверить, выходит с кодом **2** («слепота»), а не **0**: «проверки не
состоялись» не должно выглядеть как «проверки прошли». Часть стендов служебных пакетов трогает живую машину — об этом сказано
в разделе «Проверка» README пакета.

## Установка

Каждый пакет независим:

```bash
# в каталоге своего профиля ($DSH_HOME/profiles/<имя>)
pnpm add dsh-telegram-multiagent
```

Затем добавьте строку плагина в **пресет агента** — README каждого пакета говорит, куда именно и зачем.

## Зачем публикуем

Две причины. Экосистема плагинов вокруг этой платформы тонкая, а рабочий канал мессенджера — то, что большинству нужно первым. И комментарии ценнее кода: они называют ловушки, которые дают зелёные галочки без работающей системы.

Если что-то здесь сэкономит вам вечер — в этом и смысл.
