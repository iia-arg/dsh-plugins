  отказ, кандидат — шлюз active, портов 10; правила при «файла нет» побайтно = правилам при `{}` (0347b709).

## 1.0.2 — B-N-1850: `ExecReload` — перерисовать правила без каскада на шлюзы

Юнит: `ExecReload=/usr/local/libexec/dsh-gateway-ingress/boot.sh` (+1 строка, +2 строки комментария). Новый агент/порт —
`systemctl reload dsh-gateway-ingress`, а не `restart`: у всех шлюзов `Requires=dsh-gateway-ingress` (drop-in
`97-ingress-network.conf`), и `restart`/`stop` переносится на них — 08.10.2026 13:25:31Z `restart` погасил 10 шлюзов,
оборваны ходы iskra, gamma, marc. `reload` по `Requires=` не переносится. Код (`boot.sh`, `render.py`, `manage.sh`) не менялся:
`boot.sh` идемпотентен, `manage.sh apply` заменяет таблицу одной транзакцией `nft -f` после `nft -c`.
Чего не ловит: `restart`/`stop` по-прежнему каскадят (`Requires=` оставлен: без него шлюз стартует без правил, если
ingress не поднялся — замер на стенде); упавший `reload` (`render.py` без учётки) оставляет прежнюю таблицу и службу
`active` — правила НЕ обновлены, смотреть код `systemctl reload`.
