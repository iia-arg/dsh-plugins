# Изменения

## 0.1.0-alpha.7 — Э8.3: тепло как прибор; причина отделена от свойства

### Причина и свойство больше не слиты

Отбор отвергает по одному основанию — цена не влезла в предел. Вера никого не
отвергала. Прежняя сводка перечисляла отброшенных ПО ВЕРЕ внутри `prichiny`, то есть
выдавала свойство за причину: прочтя «3 с верой ниже 0.5», разбирающий шёл крутить порог
веры, который при порядке «свежесть» не участвовал вовсе. Теперь `prichiny` — только про
предел, `svoystva` — отдельным полем, печатается как «Из них:».

**Причин две, и они лечатся разным.** «Не влезает целиком» — цена одной записи больше
всего предела, такая не поднимется никогда и ни при каком порядке (лечится дроблением).
«Не поместилась в остаток» — влезла бы, но бюджет занят (лечится порядком или пределом).
Замер 04.09.2026 на живой базе: 7 из 23 отброшенных — сводки компакции ценой 4008…4841
при пределе 2000. Слив этих причин заставлял бы винить порядок за чужой дефект.

### Тепло: считается и печатается, на отбор НЕ влияет

Два замера под этим решением, оба на живой базе (31 запись):

* **порядок по теплу тождествен порядку по свежести** — различий позиций ноль. Это
  устройство, а не выборка: счётчика касаний в схеме записей нет ни одного поля, поэтому
  тепло здесь чистая функция возраста;
* **порог не отсекает ничего** — тепло 0.918…1.000 при пороге «холодной» 0.25. История
  памяти 1,7 суток при полураспаде 14 суток.

Полураспад, порог и прибавка за касание помечены гипотезами; прибавка стоит с нулевым
весом. Названо заранее, когда граница перестанет быть верной: появится счётчик касаний
либо история дорастёт до трёх полураспадов.

Отсутствие тепла — третье состояние, не холод и не ошибка.

### Имя и версия при монтаже

Пакет получил их на сутки позже соседей: правило приняли 03.09 и применили к трём
пакетам из шести. Лечили экземпляры, а не класс, и рецидив выглядел новой болезнью.
Заодно заведён безусловный след подъёма: прежде пакет говорил только при беде, то есть
исправно смонтированный был неотличим от несмонтированного.

### Числа в README заменены способом их снять

README утверждал «Три стенда, 21 проба» — стендов четыре, проб 36. Строка простояла
ложной, потому что стенд README сверял два ОПИСАНИЯ между собой и был слеп к их общему
отставанию от предмета. Число проб убрано (менялось трижды за сутки), число стендов
оставлено и теперь сверяется с диском отдельной пробой.

Записи ведутся **от первой опубликованной версии**. Редакции, существовавшие до неё,
сюда не входят: они не уезжали к получателю, и их номера ничего не адресуют снаружи.

Источник дат — реестр npm (время публикации), источник содержания — работа, которой
эти выпуски вызваны. Даты в UTC.
