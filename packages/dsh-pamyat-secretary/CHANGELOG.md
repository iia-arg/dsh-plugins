# Изменения

Записи ведутся **от первой опубликованной версии**. Редакции, существовавшие до неё,
сюда не входят: они не уезжали к получателю, и их номера ничего не адресуют снаружи.

Источник дат — реестр npm (время публикации), источник содержания — работа, которой
эти выпуски вызваны. Даты в UTC.

## 0.1.0-alpha.6 — 2026-09-03

🔴 Э4: секретарь научился снимать со среза ЗНАНИЯ отдельной дешёвой моделью, а не
только класть штатную сводку. Две работы, а не замена одной другой: сводка остаётся
оперативной записью, дистилляция даёт решения, уроки, ограничения — каждое своей
записью своего класса. Выключено по умолчанию: механизм ходит к платному чужому API.

Три вещи, купленные замером, а не рассуждением:

• журнал сессии МНОГОКАДРОВЫЙ, и `zstdDecompressSync` на всём файле молча отдаёт
  126 байт из 27 922 455 — не ошибку, а огрызок. Читаем по кадрам сами, сошлось с
  `zstd -dc` байт в байт;
• модель ДУМАЮЩАЯ: ответ приходит двумя блоками, первый `thinking`. Взять content[0]
  значит получить рассуждение вместо статьи. Берём блок по типу;
• отказ по бюджету НЕ молчаливый: `stop_reason: max_tokens` — машинный признак. Прежде
  такой случай подавался как «модель ничего не нашла»; теперь это отдельный исход
  `ne-dochitala` с числом бюджета в причине.

Затенённый срез берётся из `shadowedSeqs` события, а не вычисляется по времени.
Ключ читается в момент вызова из файла 0600 или `pass` и никогда не идёт в argv.
Пределы расхода объявлены числами: тем за заход, знаков транскрипта, минимальный срез.

`scripts.test` перебирает стенды признаком, а не перечнем, и коды проходят насквозь:
расхождение важнее слепоты. Прежний перечень пропустил бы новый стенд молча.

## 0.1.0-alpha.5 — 2026-09-03

Выпуск документационный, код не менялся: добавлен CHANGELOG.md (в состав), поле repository с directory. Номер поднят потому, что номер версии — имя предмета: правка манифеста или описания делает предмет другим, и сумма предмета при этом меняется всегда.
