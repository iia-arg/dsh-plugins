# dsh-pamyat

**Имя для набора.** Метапакет не содержит кода — он объявляет, какие 6 пакетов
памяти собраны и проверены ВМЕСТЕ, в каких точно версиях, и чем это проверено.

    dsh-pamyat-core      0.1.0-alpha.11   хранилище, журнал решений, политика записи
    dsh-pamyat-omega     0.1.0-alpha.8    долговременная память (провайдер поверх MCP)
    dsh-pamyat-secretary 0.1.0-alpha.5    сводки компакции → записи
    dsh-pamyat-byudzhet  0.1.0-alpha.6    входящий бюджет: что поднимать обратно
    dsh-pamyat-nudzh     0.1.0-alpha.9    расходный учёт: не пора ли компактить
    dsh-pamyat-restore   0.1.0-alpha.14   возврат знания в контекст: сводка после компакта и брифинг

🔴 **Эта таблица собрана ИЗ `sostav.json`, а не написана рядом с ним.** До 03.09.2026
она писалась отдельно и отстала: называла ПЯТЬ членов старых версий и не называла
шестого вовсе. Машина при этом была зелёной — стенд читает `sostav.json`, а человек
читает README. Проверка согласованности не ловит того, чего в её области нет.
Теперь стенд сверяет README с составом ПОИМЁННО и ПОВЕРСИОННО.

## 🔴 Версии ТОЧНЫЕ, диапазонов нет

Имя, за которым у разных людей оказываются разные наборы, **хуже отсутствия
имени**: расходятся такие наборы молча. Поэтому в зависимостях стоят точные
версии, а проба в стенде отвергает любой диапазон.

## 🔴 Состав проверяется, а не декларируется

`sostav.json` хранит для каждого пакета версию и **сумму предмета**; стенд
сверяет их с фактом на диске при каждом прогоне. Заявленное и настоящее не могут
разойтись молча — только с красной пробой.

**«8 из 8» означает, что учёт сходится, а НЕ что набор годен.** Стенд сверяет объявленное с действительным; годность каждого члена состава он не проверяет и проверить не может.

## Как перепроверить суммы

    summa-predmeta            сумма файла d4fc96426534a870

Всё. **Описания способа здесь нет намеренно.**

🔴 Любая команда, вписанная в справку, — ВТОРАЯ реализация способа. 03.09 мы
трижды за час разошлись на одном формате: порядок полей в строке, завершающий
перевод строки, локаль сортировки. Каждая развилка меняла число молча, и ни одна
не передаётся прозой. Вписанная в справку команда разойдётся с инструментом при
первой же его правке — и никто не заметит, потому что **справку не прогоняют**.

Опора — не в том, что число можно получить штатной командой, а в том, что способ
существует в единственном экземпляре и у него есть сумма. Сверьте сумму файла,
запустите его — получите то же число.

⚠️ Инструмент менять только НОВЫМ ИМЕНЕМ ФАЙЛА, никогда не правкой на месте: за
одну ночь одно имя носили шесть разных файлов, и глаза не отличили ни одного —
отличила только сумма.

## Проверка

    npm test

Восемь проб. Прогон обязан проходить в ТРЁХ раскладках: мастерская, плоский ящик поставки, установленное у получателя. Первая — на заведомо исправном: инструмент существует и проходит
собственный контроль зрячести. Если она красная, остальные ничего не значат.

## Что этот пакет НЕ делает

* не содержит кода и ничего не выполняет в бою — только объявляет набор;
* не заменяет установку пакетов по отдельности, если она нужна;
* не хранит знания о том, кто какую службу зовёт — это в README каждого пакета.
