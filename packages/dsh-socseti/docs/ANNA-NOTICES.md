# Уведомления Анны — кандидат notices2

Версия пакета — manifest (3.1.8). Прежние номера кандидатов и протоколы ниже — история этого участка; старые замеры не являются нынешней живой приёмкой. Общий текущий договор очереди, эхо, настройки и статуса — [REFERENCE](../REFERENCE.md).

Зовущий: `createTelegramWorker.tick`, из `main` службы socseti Анны. Вход — устойчивые `event_card_request` из Store. Круглосуточный приём события не зависит от часов доставки. Снимок пачки один раз за час, 09:00–23:00 Europe/Moscow; пустой час молчит. Новые HTTP-запросы карточек, уведомлений и их повторов запрещены с 00:00:00 до 09:00. Проверка перед fetch покрывает задержку между claim и HTTP; начатый до границы запрос может завершиться после неё.

Уведомления без кнопок группируются до 3500 единиц UTF-16. Каждое содержит собственный event ID и время события. Длинный текст разбивается без потери символов; событие считается доставленным только после подтверждения всех частей. Черновики идут отдельно со своими кнопками, nonce и hash; общего одобрения пачки нет. Ограничение 20 запросов в минуту соблюдается интервалом 3 секунды; таймер гарантирует предел отправки, а не скорость выгрузки всей очереди.

Подтверждение требует совпадения текста с допуском только конечных ASCII space/tab/CR/LF, bot ID, chat ID и положительного message ID; receipt сохраняет фактическое эхо. Неизвестный исход, включая sending после перезапуска, удерживается без автоматического повтора. Доказанный not_sent до HTTP повторяется с минимум1сек; известный отказ Telegram с retry_after1–60сек тоже допускает повтор в общем бюджете трёх попыток. Unknown не повторяется. Миграция старых queued event_card переносит MAX attempts и MAX not_before участников группы; sent/sending/unknown не переисполняет. Исходные строки сохраняются как superseded.

Проверки: `../evidence/T2-NOTICES-FINAL-FULL.log` в корне наряда, 162 проверки настоящих классов Store/Queue/Worker/API на подставных HTTP и SQLite. Отдельный reviewer: REVIEW-NOTICES.md. Стенд объёма 1201 сообщений последней пачки передаёт 1200 до границы, один хвост в 09:00. Реальные Telegram, модель и монтаж в этой проверке не участвуют. Доставка события в модель — следующий участок, этим кандидатом не доказана.
