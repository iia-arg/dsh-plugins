# Условия будущего окна G — не исполнимый лист

Окно не назначено. Полный live-счёт Codex по подпискам не допускается: OPEN-CODEX-AUTH. После решения и ворот назначенная рука подготовит отдельный лист на свежую основу; этот текст монтаж не разрешает.

До окна: снять код/версию живого процесса и суммы всех файлов; зафиксировать принятую сумму кандидата; прогнать gate на сведённом дереве; проверить inverse/restore пакета насухо в private-копии, включая новый usage-producer.mjs. Принять источник auth metadata и стык AP/R/reader.

Перед КАЖДЫМ рестартом: штатный hod-sluzhby конкретного агента/шлюза; STOP на active/unknown. Монтаж только целым пакетом назначенной рукой. Node-шлюзы перезапускать по ОДНОМУ — иначе новый код останется лишь на диске.

После каждого: проверить MainPID/InvocationID, загруженную версию/код против файлов, health/capabilities, признаки «диск=живой процесс», stop semantics и живость остальных участников. Одна сумма файла не доказывает loaded code. При отказе — штатный inverse из страховки и новый ход-guard перед рестартом; чужой ход не прерывать.

Это условия будущего конкретного листа, а не выполненные пробы/откат. Timer/AP активируются отдельным принятым окном. Живых действий автор не выполнял.
