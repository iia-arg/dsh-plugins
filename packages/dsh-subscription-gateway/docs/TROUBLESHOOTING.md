# Диагностика · Troubleshooting

Проверяйте правильный экземпляр, PID, cwd и provider до интерпретации журнала. `/health` и метаданные SDK на диске не доказывают, что работающий процесс загрузил именно эти файлы. Историю/БД не удаляют ради быстрого «починить resume»: это стирает доказательства и может объединить неправильные поколения.
Identify the correct instance, PID, cwd and provider before interpreting logs. `/health` and disk SDK metadata do not prove the running process loaded those files. Do not delete history/databases to quickly repair resume: it removes evidence and can merge incorrect generations.

Optional backend не должен ронять старт. · Check Node ≥ 22.22.0 and package contents. Optional backend should not crash startup. |
| Health 503: пропуск недоступен · Health 503 ingress unavailable | Ошибка пути/владельца/прав/формата ключа · Wrong key path, owner, mode, format | Восстановить правильный private 64 hex file, не выводить значение · Restore the correct private 64 hex file without logging its value |

| HTTP 200 без завершённого ответа · Valid HTTP 200 but no answer | Ошибка NDJSON или оборванный поток · NDJSON error or incomplete stream | Читать terminal event/error, а не только HTTPstatus · Read terminal event/error, not status alone |
| Запрос v2 получил 400 · V2 request 400 | Identity/cwd/generation/type не совпали · Missing identity, mismatched cwd, generation/type | Передавать session-owned envelope или stateless; не downgrade to v1 · Send a session-owned envelope or stateless, not a v1 downgrade |
| Слишком длинный ввод · Prompt too long | Вход/хвост выше vendor limit · Full input/tail exceeds vendor bound | Сверить char/token units и current plan; не считать живую session мёртвой · Check character/token units and plan; do not classify a live session as stale |
| Не найдены rollout/сессия · No rollout/session found | Mapping остался после потери rollout · Mapping survives lost SDK state | Разобрать привязку и bounded recovery; не удалять другие sessions · Inspect mapping and bounded recovery; do not delete unrelated sessions |
| Инструменты не видны после регистрации · Tools absent despite plugin registration | Нет descriptor/bind/имя занято · Missing bridge descriptor, MCP bind failure, name collision | Проверить per-turn descriptor и model init tools, затем platform invoke · Check per-turn descriptor/model-init tools, then platform invocation |
| MCP требует одобрения · MCP tool requires approval | MCP approvals не согласованы · SDK config disagrees with noninteractive route | Проверить default_tools_approval_mode и права process; не обходить platform deny · Check SDK MCP approval config and process rights; do not bypass platform denial |
| Нет протокола read_image · read_image protocol absent | Версии bridge/gateway не совместимы · Gateway/bridge version mismatch | Монтировать совместимую пару, проверить stored image integration · Deploy a compatible pair and verify stored-image integration |
| Исход ACK управления неизвестен · Control ACK unknown | Закрытый запрос, timeout, неверная привязка либо отказ SDK · Closed request, timeout, wrong binding or SDK failure | Проверить exact target и фактический SDK turn; не повторять на latest thread · Check exact target/actual SDK turn; do not replay on a latest thread |
| Сигнал повторяется или слепнет · Pressure signal repeats or goes blind | Порог/SDK/schema неизвестны · Unknown threshold/SDK telemetry/schema mismatch | Проверить event timestamps/source/reader, не принимать 0 без наблюдения · Check event timestamps/source/reader, not unobserved zero |
| Письмо продолжения отсутствует · Continuation missing | Ящик/права/предел продолжений · Wrong mailbox/permissions/loop ceiling reached | Сверить receipt on mailbox side и limit 2; не считать rename началом хода · Check mailbox-side receipt and limit 2; rename is not turn start |
| Модель не совпадает с запросом · Different model than requested | Событие model reroute · Server rerouted/model notification | App-server прекращает ход после уведомления; ранний text уже отдан · App-server stops after notification; earlier text was already emitted |
| Отказ после изменения групп · Permission still denied after group change | Живой процесс сохранил старые группы · Running process kept old groups | Проверить /proc/<PID>/status и restart по окну, не только новый id process · Check live /proc status and restart in a window, not only a new id process |

После восстановления снова пройти healthy→контролируемый отказ→healthy на копии, где это безопасно. Сравнивайте source SHA, vendor SDK version и фактический source загруженного процесса. Живые публикации/модельные действия требуют отдельного мандата; документационная проверка не запускает их автоматически.
After recovery, repeat healthy→controlled failure→healthy on a copy where safe. Compare source SHA, vendor SDK version and the running process's loaded source. Live publications/model actions require their own authorization; documentation verification does not run them automatically.
