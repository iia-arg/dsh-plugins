# Гостевой экземпляр · Guest instance

Это шаблон ограниченного Claude gateway, который отключает встроенные инструменты SDK exact значением `GATEWAY_INSTRUMENTY_DVIZHKA=net`. Он не выключает платформенные MCP-инструменты и не фильтрует глобальную память. Codex ветка этим параметром не ограничивается.
This is a restricted Claude gateway template that disables SDK built-in tools with exact `GATEWAY_INSTRUMENTY_DVIZHKA=net`. It does not disable platform MCP tools or filter global memory. This parameter does not restrict the Codex branch.

Drop-in должен применяться после обычных instance/template overrides. Он сбрасывает SupplementaryGroups и EnvironmentFile/Environment, включает NoNewPrivileges и отдаёт шлюзу ровно одну подписку: `ExecStartPre=+` зовёт `gost-podpiska-vybor` (ставится в `/usr/local/libexec/gost-podpiska-vybor`, root 0755), тот берёт `GATEWAY_TOKEN_FILE` из `instance-<гость>.env` и кладёт копию этого токена в `RuntimeDirectory` юнита (systemd удаляет её при остановке); `LoadCredential` сброшен (B-N-1621). Проверяйте NSS memberships отдельно: пустое поле юнита не удаляет группы учётки из системного каталога.
The drop-in must apply after normal instance/template overrides. It resets SupplementaryGroups and EnvironmentFile/Environment, enables NoNewPrivileges and gives the gateway exactly one subscription: `ExecStartPre=+` runs `gost-podpiska-vybor` (installed at `/usr/local/libexec/gost-podpiska-vybor`, root 0755), which takes `GATEWAY_TOKEN_FILE` from `instance-<guest>.env` and copies that token into the unit's `RuntimeDirectory` (systemd removes it on stop); `LoadCredential` is reset (B-N-1621). Verify NSS memberships separately: clearing unit fields does not remove account groups from the system database.

Сохранённые directives шаблона содержат deployment-specific paths. Не устанавливайте их на другой машине вслепую: подготовьте новый root-owned read-only runtime и соответствующий EnvironmentFile/ExecStart/ExecStartPre/RuntimeDirectory комплект, затем проверьте на копии. Runtime не должен содержать авторизацию чужих движков.
The retained template directives contain deployment-specific paths. Do not blindly install them on another host: prepare a new root-owned read-only runtime and matching EnvironmentFile/ExecStart/ExecStartPre/RuntimeDirectory set, then test a copy. The runtime must not contain another engine's authentication data.

Launcher требует ровно один gateway path, exact net и CREDENTIALS_DIRECTORY. Selection распознаёт только три именованных token-podpiska файла (1–3); новая subscription selection громко отказывает. Проверка доступности credential не равна действующей авторизации у поставщика.
The launcher requires exactly one gateway path, exact net and CREDENTIALS_DIRECTORY. Selection recognizes only three named token-podpiska files (1–3); a new subscription selection fails explicitly. Credential readability does not prove valid vendor authentication.

Две пробы независимы: process UID/groups не читает общий secret file, и `system/init.tools` действительно не содержит built-ins, но содержит разрешённый MCP. Одно лишь `tools:[]` в файле не доказывает, что живой SDK прочитал его. Permission mutation и восстановление делаются только на отдельной тестовой учётке/юните.
Two checks are independent: process UID/groups cannot read shared secret files, and `system/init.tools` actually omits built-ins while retaining allowed MCP tools. A `tools:[]` line alone does not prove a live SDK read it. Permission mutation/restoration belongs on a separate fixture account/unit.

Стенд `test/stend-gost-odna-podpiska.sh` (от root, только чтение): учётка гостевого шлюза читает токены ровно одной подписки, и это подписка из env; коды 0 — да, 1 — нарушение (названо), 2 — слепота. Запуск на sadik — недельный обход (dsh-obhod-stendov).
The `test/stend-gost-odna-podpiska.sh` stand (as root, read-only): the guest gateway account reads tokens of exactly one subscription, the one from env; exit 0 — yes, 1 — violation (named), 2 — blindness. On sadik it runs in the weekly sweep (dsh-obhod-stendov).
