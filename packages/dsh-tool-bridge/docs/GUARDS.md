# Проверки и сторожа · Guards and checks

## Защита во время исполнения · Runtime safeguards

| Вызывающий · Caller | Что контролирует · Coverage | Куда сообщает · Output | Граница · Boundary |
|---|---|---|---|
| HTTP обработчик · handler | TTL, владелец и каталог · Ticket TTL/owner/catalog | 403 либо ok:false, журнал · 403 or ok:false, log | Не sandbox root/process memory · Not root/process memory isolation |
| create_goal | Человеческое полномочие и квота · Human authority + rolling quota | Ошибка/источник/занятость · Error/source/usage | Память quota сбрасывается на restart · Quota memory resets on restart |
| schedule_create/update | Cron и повторный интервал · Cron/repeat interval | Ошибка или pravkaIntervala · Error or adjusted-delay explanation | Не все schedule sources и не общий агентский бюджет · Not every schedule source or a global agent budget |
| turn/end callback | Полоса, сутки, час и свидетель истории · Streak/day/hour/history witness | Журнал; alert command; файл notice · Log; alert command; notice file | Только корневые nonscoped sessions, после хода · Root nonscoped sessions only, after turn |
| imageContent | Пределы и идентичность вложения · Trusted stored image bounds/identity | Ошибка до экспорта · Tool error before exporting bytes | Не произвольный media downloader · Not an arbitrary media downloader |

Строка остановки сообщает числа, сессию, пояс и результат удаления. Сообщение, записанное в notice directory, означает локальную запись, а не доставку адресату. `DSH_ALERT_CMD` должен иметь собственного читателя/курьер; успешный exit команды не является подтверждением чтения человеком.
Stop logs report counts, session, zone and deletion outcome. A notice-directory file proves local writing, not recipient delivery. `DSH_ALERT_CMD` needs its own reader/courier; a successful command exit does not prove a human read it.

При недоступных session events guard отодвигает одноразовый срок на 86400 seconds и сообщает слепоту. Turn-end safeguard удаляет напоминания после завершения хода. Напоминания/события, которые платформа не сообщает этим API, не входят в гарантированный охват. Goal rounds и job wake budgets контролируют свои сервисы.
When session events are unavailable, the guard defers one-shot scheduling by 86400 seconds and reports blindness. The turn-end safeguard removes reminders after the turn completes. Reminders/events not exposed by platform APIs are outside guaranteed coverage. Goal rounds and job wake budgets are controlled by their own services.

`npm test` запускает все `test/stend-*.mjs` по очереди и сводит код: была хоть одна 1 — итог 1; иначе — последний иной ненулевой код (чаще всего 2). `npm test` runs all `test/stend-*.mjs` in turn and folds the code: any 1 gives 1; otherwise the last other non-zero code (usually 2). General outcomes are 0=pass, 1=mismatch, 2=missing prerequisites; do not turn 2 into green. Some tests exit explicitly, so execute each in a separate Node process.

```bash
DSH_TEST_APP="/srv/<instance>/dsh" node test/stend-scoped-sessions.mjs
DSH_TEST_APP="/srv/<instance>/dsh" node test/stend-live-tools.mjs
node test/stend-heartbeat.mjs
```

## Проверка обновления · Upgrade verification

На копии извлеките схемы из выбранного platform root и сравните JSON; только после проверки заменяйте исходные generated files. `izvlech-pamyat.mjs` и `izvlech-vydacha.mjs` принимают также каталог соответствующего модуля. Их выполнение регистрирует тела в fixture context, не запускает модель. Нельзя подменять слепоту пустым JSON.
On a copy, extract schemas from the selected platform root and compare JSON; replace generated files only after verification. `izvlech-pamyat.mjs` and `izvlech-vydacha.mjs` also take their module directory. They register bodies in a fixture context without running a model. Never replace missing prerequisites with empty JSON.

Для транспортных изменений отдельно проверьте: пакет/порт/живой PID правильные, descriptor не пуст, имя MCP закреплено, инструмент реально вызван, пропуск отозван после конца хода. Для защиты используйте исправное→внесённая порча→возврат на копии; порча обязана менять то свойство, которое читает прибор.
For transport changes, separately check the package/port/live PID, nonempty descriptor, pinned MCP name, actual invocation and ticket revocation after turn end. For safeguards use healthy→confirmed mutation→restoration on a copy; the mutation must affect the property observed by the test.

Часовой потолок охватывает every_seconds, daily, weekly, after_seconds и одноразовое at (срок пересчитывается в задержку; отодвинутое at заменяется на after_seconds): постановка/изменение времени повторов при полном окне отказывает, одноразовый срок отодвигается, turn/end снимает все действующие виды. Это проверка после хода, не атомарный допуск доставок: одновременные доставки до конца хода могут превысить предел. Нет таймера повтора удаления; одна попытка на напоминание в одной проверке, следующая — на следующем turn/end при сохраняющемся превышении.
The hourly ceiling covers every_seconds, daily, weekly, after_seconds and one-shot at (the deadline becomes a delay; a deferred at is replaced with after_seconds): recurring creation/timing updates refuse a full window, one-shot delays are deferred and turn/end removes all existing kinds. This is a post-turn check, not atomic delivery admission: simultaneous deliveries before turn end can exceed the ceiling. Deletion has no retry timer; each check attempts each reminder once, with another attempt on a later turn/end if the limit remains exceeded.
