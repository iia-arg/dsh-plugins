# Диагностика и восстановление · Troubleshooting

Все действия ниже начинаются с определения правильного процесса, копии и profile. Не записывайте пропуски в диагностические файлы или argv. Если ошибка относится к native сервису, исправляйте его настройку/регистрацию, не добавляйте обход через shell.
Start every procedure by identifying the correct process, package copy and profile. Do not write tickets into diagnostic files or argv. If a native service fails, repair its configuration/registration rather than adding a shell bypass.

После исправления повторите именно отказавший сценарий и восстановите нормальный вход. Перезапуск не должен удалять сохранённую платформенную историю или pending reminders без отдельного решения оператора. Код 2 стенда означает, что доказательства всё ещё нет.
After repair, rerun the failing scenario and restore a normal input. Restart must not delete durable platform history or pending reminders without a separate operator decision. Test exit 2 means evidence is still unavailable.
