## 0.4.1 — 2026-09-03

- **Отказ вместо тихого нуля при пропаже источника событий** (`session.events`): в
  обработчике статуса отсутствие журнала теперь возвращается с ГРОМКОЙ строкой, а не
  бросает исключение в жизненный цикл агента (бросок зависал агента в «running»).
- **Счётчик виденных вызовов** (правило 8.9): на каждом `schedule_create` пишется
  `видел N, отказал M` — ноль строк в журнале больше не двусмыслен.
- **Пустой массив `resetKinds` = «не настроено»**: schemastery для `z.array()` без
  `.default()` отдаёт `[]`, а не `undefined`; теперь `[]` трактуется как отсутствие,
  вступает умолчание `['user','a2a']`. Выразить «не сбрасывать никогда» пустотой нельзя
  намеренно — понадобится, заведём явный способ.

## 0.4.0 — 2026-09-02

- **Часовой потолок** (`maxPerHour`): не более N автономных пробуждений в скользящий час,
  считается по `dispatchTimes` из журнала. Отказ несёт код и срок освобождения.
- **Сброс полосы по внешнему слову** (`resetKinds: ['user','a2a']`): полосу рвут человек и
  координатор; этикетка честно перечисляет виды.
