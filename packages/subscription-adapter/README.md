# dsh-subscription-adapter

Плагин-адаптер подписочного маршрута для платформы dsh.

## 🔴 Три имени у одного предмета — не путать

    каталог в бою   /opt/iskra/plugins/claude-oauth
    имя пакета      dsh-subscription-adapter   ← по нему ищет прибор «перед подъёмом»
    export name     subscription-gateway       ← им подписаны строки в журнале

И ЧЕТВЁРТОЕ, самое опасное: в реестре npm под именем `subscription-gateway` лежит
**другой предмет** — служба-шлюз из `/opt/claude-oauth`. Это не версии одного, а
разные вещи с одним именем. Сверять их как один объект — красное по построению.

## Что здесь появилось 05.09.2026

Строка подъёма с ИМЕНЕМ ПАКЕТА и версией из манифеста (долг 108): без неё прибор
«перед подъёмом» пишет «НЕ СВЕРЯЕМ», и пакет выпадает из проверки подъёма молча.

## 🔴 Почему пакет внесён в репозиторий только сейчас

До 05.09.2026 он жил ТОЛЬКО на боевом диске: ни в npm, ни в дереве. То есть правка в
нём не оставляла следа, откатить было некуда, кроме страховки, и никакая приёмка не
могла его посмотреть. Внесён, чтобы у правок появилась история.
Заодно из каталога пакета убраны ДЕВЯТЬ старых копий основного файла (четыре из них —
не под маской `.bak-*`, поэтому учёт их не исключал, а читались они как предмет).
